## 1. 引言

### 1.1 编写目的

本文档旨在明确"智能仓储物料识别与分拣系统"的功能需求与非功能需求，为系统设计、开发、测试和验收提供依据。本文档的预期读者包括项目开发人员、测试人员、课程指导教师及项目评审人员。

### 1.2 项目背景

随着电商与制造业的快速发展，仓储物流环节对自动化、智能化的需求日益迫切。传统人工分拣存在效率低、错误率高、人力成本大等问题。本项目将机器视觉、深度学习与多传感器融合技术相结合，设计一套智能物料识别与分拣系统，实现仓储物料的自动识别、校验与分拣管理。

本项目为《制造智能技术》课程设计，要求运用课程所学至少3章相关技术手段，实现完整B/S架构的可运行demo。

### 1.3 术语定义

| 术语 | 定义 |
|------|------|
| YOLO | You Only Look Once，一种实时目标检测算法 |
| 多传感器融合 | 将多个传感器的数据进行综合处理，获得更可靠的判断结果 |
| B/S架构 | Browser/Server架构，浏览器/服务器模式 |
| SPC | Statistical Process Control，统计过程控制 |

## 2. 总体描述

### 2.1 产品愿景

本系统面向智能仓储物料分拣场景，通过工业相机采集物料图像，基于深度学习目标检测算法实现多类别物料的实时识别与定位；融合视觉信息与重量传感器、红外传感器数据进行多维度属性判定；通过Web界面实现检测结果展示、库存管理、传感器数据监控等功能，形成完整的业务闭环。

### 2.2 用户特征

| 用户角色 | 描述 | 技术水平 |
|----------|------|----------|
| 仓储管理员 | 负责日常物料检测、库存管理、系统监控 | 中等，能操作Web界面 |
| 系统维护员 | 负责系统配置、参数调整、故障排查 | 较高，了解技术架构 |
| 课程评审教师 | 负责系统功能验证、代码审查、答辩评分 | 高，专业技术人员 |

### 2.3 运行环境

**硬件环境：**
- 服务器/工控机：CPU 4核以上，内存8GB以上
- 工业相机：分辨率不低于1280×720，帧率不低于30FPS
- 重量传感器：量程0-50kg，精度±5g
- 红外传感器：检测距离0-50cm

**软件环境：**
- 操作系统：Windows 10/11 或 Linux
- Python版本：3.10及以上
- 数据库：SQLite 3
- Web浏览器：Chrome、Edge、Firefox最新版本

### 2.4 设计约束

1. **技术约束**：必须运用《制造智能技术》课程所学至少3章相关技术手段
2. **架构约束**：必须实现完整B/S架构，包括前端UI、后端服务、数据库、算法模块
3. **数据约束**：使用公开工业数据集（SORDI），不要求真实企业数据
4. **时间约束**：课程设计周期10天
5. **AI使用约束**：允许使用AI编程工具，但须如实披露并确保理解代码逻辑

### 2.5 假设与依赖

1. 假设网络环境稳定，前后端通信正常
2. 假设传感器数据可通过模拟方式生成（无硬件时）
3. 依赖公开数据集SORDI提供训练和测试数据
4. 依赖Python生态中的FastAPI、SQLAlchemy、NumPy、Pillow等开源库
5. 假设用户使用现代浏览器访问系统

### 3.2 物料检测模块

#### 3.2.1 图像上传

**需求编号：** FR-DET-001
**需求描述：** 用户可通过Web界面上传物料图像，支持JPG、PNG、BMP格式
**输入：** 图像文件（最大10MB）
**处理：**
1. 验证文件格式和大小
2. 保存图像到服务器
3. 调用检测算法
**输出：** 检测结果（目标类别、置信度、位置、融合结果、异常结果）
**优先级：** 高

#### 3.2.2 目标检测

**需求编号：** FR-DET-002
**需求描述：** 基于YOLO目标检测算法，对上传图像进行物料识别与定位
**技术方向：** 机器视觉与深度学习
**输入：** 图像文件
**处理：**
1. 图像预处理（缩放、归一化、居中填充至640×640）
2. YOLO模型推理
3. NMS后处理
4. 坐标转换
**输出：** 检测目标列表（类别ID、类别名称、置信度、边界框坐标）
**性能要求：** 单帧推理时间不超过100ms
**优先级：** 高

#### 3.2.3 多传感器融合

**需求编号：** FR-DET-003
**需求描述：** 融合视觉识别结果与重量传感器、红外传感器数据，进行一致性校验
**技术方向：** 传感器与多源数据融合
**输入：** 视觉识别结果（类别、置信度）、传感器数据（重量、红外到位信号）
**处理：**
1. 红外传感器检测物料是否到位
2. 重量传感器采集物料重量
3. 重量滑动平均滤波
4. 类别-重量范围一致性校验
5. 加权融合决策（视觉权重0.6，传感器权重0.4）
6. 输出判定结果（通过/警告/拒绝）
**输出：** 融合判定结果（状态、置信度、原因列表）
**优先级：** 高

#### 3.2.4 异常检测

**需求编号：** FR-DET-004
**需求描述：** 基于统计学习方法，对检测结果进行多维度异常分析
**技术方向：** 工业数据分析与异常检测
**输入：** 检测结果（类别、置信度、尺寸、重量）
**处理：**
1. 维护各类别历史数据滑动窗口
2. 置信度异常检测（Z-Score）
3. 目标尺寸异常检测（Z-Score）
4. 检测频率异常检测
5. 重量异常检测（Z-Score）
6. 多维度加权综合评分
7. 异常等级判定（正常/轻度/严重）
**输出：** 异常检测结果（是否异常、异常分数、等级、原因、各维度评分）
**优先级：** 中

### 3.3 库存管理模块

#### 3.3.1 库存查询

**需求编号：** FR-INV-001
**需求描述：** 用户可查看所有物料的库存信息，支持按类别筛选
**输入：** 筛选条件（可选）
**输出：** 库存列表（类别、数量、位置、最低/最高库存、状态）
**优先级：** 高

#### 3.3.2 入库操作

**需求编号：** FR-INV-002
**需求描述：** 用户可对指定物料执行入库操作，增加库存数量
**输入：** 物料ID、入库数量
**处理：** 验证数量有效性 → 更新库存 → 记录操作
**输出：** 操作结果（成功/失败、当前库存）
**优先级：** 高

#### 3.3.3 出库操作

**需求编号：** FR-INV-003
**需求描述：** 用户可对指定物料执行出库操作，减少库存数量
**输入：** 物料ID、出库数量
**处理：** 验证数量有效性 → 检查库存是否充足 → 更新库存
**输出：** 操作结果（成功/失败、当前库存）
**异常：** 库存不足时返回错误提示
**优先级：** 高

#### 3.3.4 库存预警

**需求编号：** FR-INV-004
**需求描述：** 系统自动标记库存不足（低于最低库存）和库存充足（高于最高库存）的物料
**处理：** 实时比对库存数量与阈值
**输出：** 状态标签（正常/库存不足/库存充足）
**优先级：** 中

**优先级：** 低

### 3.5 检测记录模块

## 4. 非功能需求

### 4.1 性能需求

| 指标 | 要求 | 说明 |
|------|------|------|
| 图像检测响应时间 | ≤ 3秒 | 从上传到返回完整结果 |
| 目标检测推理时间 | ≤ 100ms | 单帧图像推理 |
| API响应时间 | ≤ 500ms | 普通查询接口 |
| 并发用户数 | ≥ 5 | 同时在线用户 |
| 页面加载时间 | ≤ 3秒 | 首屏加载 |
| 支持图像分辨率 | ≤ 4K | 最大支持3840×2160 |

### 4.2 可靠性需求

1. 系统连续运行2小时无崩溃
2. 数据库操作失败时自动回滚
3. 文件上传失败时给出明确错误提示
4. 算法模块异常时不影响系统整体运行
5. 数据备份：检测记录和库存数据持久化存储

### 4.3 可用性需求

1. 界面采用中文显示，操作简洁直观
2. 提供操作反馈（成功/失败提示）
3. 支持响应式布局，适配不同屏幕尺寸
4. 导航清晰，功能模块划分明确
5. 提供系统状态实时显示

### 4.4 可维护性需求

1. 代码模块化设计，各功能模块独立
2. 遵循Python编码规范（PEP 8）
3. 关键函数和类有文档注释
4. 配置参数集中管理，便于调整
5. 提供自动化测试用例

### 4.5 可扩展性需求

1. 支持新增物料类别（修改配置即可）
2. 算法模块可替换（如更换检测模型）
3. 数据库可迁移（从SQLite到MySQL/PostgreSQL）
4. 支持新增传感器类型
5. API接口设计遵循RESTful规范，便于第三方集成

### 4.6 安全性需求

1. 输入数据验证，防止SQL注入
2. 文件上传类型和大小限制
3. 敏感配置不硬编码在代码中
4. 数据库文件访问权限控制
5. API错误信息不泄露系统内部细节

## 6. 数据需求

### 6.1 数据实体

系统包含以下核心数据实体：

1. **检测记录（DetectionRecord）**
   - 图像信息（名称、路径）
   - 检测结果（类别ID、类别名、置信度、边界框）
   - 融合结果（状态、置信度、重量）
   - 异常信息（是否异常、分数、原因）
   - 分拣状态、目标位置
   - 时间戳

2. **库存物料（InventoryItem）**
   - 类别ID、类别名称
   - 库存数量、存放位置
   - 最低/最高库存阈值
   - 描述信息
   - 时间戳

3. **传感器数据（SensorData）**
   - 传感器类型、传感器ID
   - 数值、单位
   - 关联检测记录ID
   - 时间戳

4. **系统配置（SystemConfig）**
   - 配置键、配置值
   - 描述信息
   - 更新时间

5. **系统日志（SystemLog）**
   - 日志级别、模块
   - 日志内容
   - 时间戳

### 6.2 数据集

**数据集来源：** SORDI（Smart Object Recognition Dataset for Industry）工业数据集

**数据集规模：**
- DR-1：9,325张图像
- DR-2：36,943张图像
- 总计：46,268张标注图像

**选择子集：**
- 类别数：6类仓储相关物料
- 每类样本：400张
- 去重后总计：2,333张
- 训练集：1,633张（70%）
- 验证集：466张（20%）
- 测试集：234张（10%）

**检测类别：**
