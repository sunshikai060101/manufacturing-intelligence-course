# 制造-智能-课程

制造智能技术课程设计，包含 AI 工具学习、Git 学习、选题调研及后续系统开发。

## 一、数据来源

本项目为「基于机器视觉与多传感器融合的智能仓储物料识别与分拣系统」，数据用于 YOLOv8 目标检测模型训练。

### 1.1 数据来源

| 数据来源 | 说明 | 数量预估 |
|----------|------|----------|
| 公开数据集 | Google Images / Kaggle 搜索相关物料图片 | 约 500-1000 张 |
| 自行采集 | 使用相机拍摄实际物料图像（不同角度、光照） | 约 300-500 张 |
| 数据增强 | 通过旋转、翻转、缩放、色彩抖动等方式扩充 | 扩充至 2000+ 张 |

Kaggle 数据集地址：https://www.kaggle.com/datasets

详细说明请查看 `data/原始/README.md`。

### 1.2 数据集类别

1. 长方体纸盒
2. 圆柱形易拉罐
3. 球形物体（如乒乓球）
4. 不规则形状零件
5. 袋装物品

### 1.3 标注格式

YOLO 格式（.txt 文件，每行：class_id x_center y_center width height）。

标注工具：LabelImg

注：由于图像文件数量较多、体积较大，本仓库不直接存储原始图像文件。请通过上述方式获取图像，并按 `data/原始/` 目录结构放置。

## 二、数据预处理

### 2.1 预处理程序

预处理程序位于 `data/处理后/preprocess.py`。

### 2.2 预处理功能

1. 图像有效性检查：剔除损坏、格式不支持、尺寸过小的图像
2. 图像格式统一：统一转换为 RGB、JPG 格式，等比例缩放并居中填充至 640×640
3. 标注文件匹配：校验每张图像的对应标注文件，剔除无标注样本
4. 标注坐标校验：检查 YOLO 格式标注的格式、类别 ID 范围、坐标范围（越界自动裁剪）
5. 数据集划分：按 7:2:1 比例随机划分为训练集、验证集、测试集
6. 数据索引生成：生成 `processed_index.csv`，记录每条数据的文件名、路径、类别、划分、状态等信息

### 2.3 运行方式

```
cd data/处理后
pip install opencv-python numpy pandas Pillow
python preprocess.py
```

### 2.4 预处理结果

| 统计项 | 数值 |
|--------|------|
| 原始图像总数 | 约 1100 张 |
| 有效图像数 | 约 1050 张 |
| 训练集 | 约 735 张（70%） |
| 验证集 | 约 210 张（20%） |
| 测试集 | 约 105 张（10%） |
| 处理后尺寸 | 640×640 像素 |
| 处理后格式 | JPG |

处理后的数据索引文件为 `data/处理后/processed_index.csv`。

详细说明请查看 `data/处理后/README.md`。
