# 数据说明

## 1. 数据集名称

SORDI.ai Industrial Scene 01

## 2. 数据集类型

公开数据集，主要用于工业与仓储场景下的目标检测与机器视觉研究。

## 3. 数据集来源

数据集来源于 Kaggle，由 SORDI.ai 发布。

数据集地址：

https://www.kaggle.com/datasets/sordi-ai/industrial-scene-01-dataset

## 4. 数据集用途

本项目将该数据集用于智能仓储物料识别模块的机器视觉数据基础。

通过目标检测模型识别仓储场景中的物料及相关目标，为后续物料分类、抓取定位和自动分拣提供视觉信息。

## 5. 数据集规模

该数据集包含约 4.6 万张工业与仓储场景图像，并提供对应的目标检测标注。

数据集主要包含 36 类目标。

由于原始数据集规模较大，本项目不直接将完整原始数据集上传至 GitHub 仓库，而是在仓库中记录数据集来源、数据说明和后续预处理方法。

## 6. 主要目标类别

本项目重点关注与仓储物料识别和分拣相关的目标类别，包括：

- cardboard_box：纸箱
- eps_box：泡沫箱
- pallet：托盘
- container：容器
- locker：储物柜
- cabinet：柜体
- forklift：叉车

后续根据实际模型训练需求进一步筛选目标类别。

## 7. 数据标注

原始数据集提供目标检测标注信息。

本项目后续将根据 YOLO 目标检测模型的输入要求，对原始标注进行格式整理，并建立统一的数据索引。

## 8. 数据预处理计划

本项目计划对原始数据进行以下预处理：

1. 检查图像文件是否完整；
2. 检查图像与标注文件是否能够正确对应；
3. 删除无法读取或标注异常的数据；
4. 统一图像格式；
5. 根据模型需求调整图像尺寸；
6. 将目标检测标注转换为 YOLO 格式；
7. 按照训练集、验证集和测试集进行划分；
8. 建立处理后的数据索引文件。
