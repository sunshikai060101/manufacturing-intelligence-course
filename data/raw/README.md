# 原始数据

本目录用于存放「基于机器视觉与多传感器融合的智能仓储物料识别与分拣系统」项目的原始数据集。

## 一、数据来源

| 数据来源 | 说明 | 数量预估 |
|----------|------|----------|
| 公开数据集 | Google Images / Kaggle 搜索相关物料图片 | 约 500-1000 张 |
| 自行采集 | 使用相机拍摄实际物料图像（不同角度、光照） | 约 300-500 张 |
| 数据增强 | 通过旋转、翻转、缩放、色彩抖动等方式扩充 | 扩充至 2000+ 张 |

Kaggle 数据集搜索地址：https://www.kaggle.com/datasets

搜索关键词：warehouse objects、inventory items、product recognition、快递盒、易拉罐、乒乓球、机械零件、包装袋。

## 二、物料类别

| 类别ID | 类别名称 | 说明 |
|--------|----------|------|
| 0 | 长方体纸盒 | 快递盒、包装盒等 |
| 1 | 圆柱形易拉罐 | 易拉罐、金属罐等 |
| 2 | 球形物体 | 乒乓球、球类物品等 |
| 3 | 不规则形状零件 | 机械零件、异形物品等 |
| 4 | 袋装物品 | 包装袋、软包装等 |

## 三、标注格式

YOLO 格式（.txt 文件），每行：`class_id x_center y_center width height`，坐标为归一化值（0到1之间）。

标注工具：LabelImg（https://github.com/HumanSignal/labelImg）
